# Challenge logos

Drop HackTheBox challenge art here, then point a writeup at it:

```yaml
image: insomnia        # matches insomnia.png / .svg / .webp ... in this folder
```

- Square PNG (transparent background) at 128x128 or larger looks best.
- Machine and Sherlock art lives in `../machines/` instead.
- No image? The card falls back to the first two letters of the title.

This file only exists so Git keeps the folder; delete it once there are
real logos in here.
